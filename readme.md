# Técnica de Programação 💻

Bem-vindo ao repositório oficial da disciplina de **Técnica de Programação**. Este espaço é destinado à organização de materiais, exemplos de código e acompanhamento do cronograma letivo.

---

## 🚀 Sobre a Disciplina
O foco é o aprendizado de lógica de programação utilizando a linguagem **Python**, abordando desde os conceitos fundamentais até a manipulação de estruturas de dados. No decorrer da disciplina será ministrado um minicurso de robótica que visa a integração dos conceitos com o hardware (**ESP32**).

### 🛠️ Ferramentas Sugeridas
* [Python 3.x](https://www.python.org/)
* [Visual Studio Code](https://code.visualstudio.com/) ou [Thonny IDE](https://thonny.org/)
* [Wokwi](https://wokwi.com/) (Simulador para práticas de ESP32)
